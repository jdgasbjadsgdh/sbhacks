# Web source

This folder contains the readable connectivity/loading plugin and installer
source. Use the complete [Web ZIP](../README.md#downloads) for installation: it
contains the generated `payload-data.js` and `www.starbreak.com` game override
required by `INSTALL.html`. They are packaged in the ZIP rather than duplicated
in this source folder. See [START HERE.txt](START%20HERE.txt).

Web v2 includes a guarded current-tab Disconnect + hold button and compact
Rush-only controls. Native movement/Sync is not included. Preview requires
Connect within ten seconds or you will be sent to Eschaton.
