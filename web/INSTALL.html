Install loading controls for WebBreak

This local installer adds Rush hold, room preview, boss hold, free camera and short button guides. Hide all UI removes the panel and its tab; F8 restores them. It keeps existing WebBreak settings and saves a backup before updating.

  1. Open this file in Chrome or Edge.
  2. Choose the same Overrides folder already selected in your game’s DevTools. Choose the folder containing www.starbreak.com, or that domain folder itself.
  3. Click Install / update. Reload your web game with DevTools open whenever you are ready.
Choose your Overrides folder to begin.
No account password, downloads, game restart or browser refresh is performed by this installer.

Arm all tabs: after updating each game tab, check “Arm all connected web tabs” below the panel buttons, then choose Rush hold, Boss hold or Timed. It reaches tabs in the same browser profile; active holds are left alone. Separate profiles and native clients are separate groups.

First time using WebBreak?

In the game tab, open DevTools, then Sources → Overrides → Select folder for overrides. Choose an empty folder and click Allow. Select that same folder here and install. Keep DevTools open when reloading and playing.

Alternative: copy the included www.starbreak.com folder into your Overrides folder. The installer is preferred when updating because it preserves custom WebBreak settings.

SC quick guide

Before the last generator is destroyed, select Rush hold. Wait through the early hold, then select Preview room to look at the boss. Select Reconnect when ready to spawn. Preview ends the early hold and cannot restore it. Server disconnects and mission expiry can still interrupt either hold.

F8 opens/closes the panel. F9 arms the last mode or cancels an unused arm. F10 continues loading or reconnects. Closing the panel keeps the hold active.
